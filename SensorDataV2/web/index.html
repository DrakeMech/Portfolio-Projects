Transformation Function Template

            

                
def my_transformation(value):
    """
    Transform a sensor value to MIDI CC range.
    
    Args:
        value: Raw sensor reading
        
    Returns:
        Integer between 0-127 (MIDI CC range)
    """
    # Your logic here
    return max(0, min(127, int(value)))

            

            
            
Usage in Launcher

            

                
1. Save your custom transformation code here
2. Open the launcher desktop app
3. Create a Mapping:
   - Sensor: /accelerometer/x
   - CC Number: 10
   - Transformation: myTransformation
4. Sensor values → transformation → MIDI CC sent
